HESABU AI — LAUNCH GUIDE

1. Extract this ZIP.
2. Open the hesabu-ai folder.
3. Upload its CONTENTS to a GitHub repository. package.json must be at the
   repository root. Include api/, server/, src/, public/, scripts/ and tests/.
4. Import the GitHub repository in Vercel.
5. Framework: Other. Node: 24.x. Install: npm ci.
   Build: npm run build. Output: dist.
6. Add these Vercel environment variables:
   OPENAI_API_KEY       Your own OpenAI API key
   OPENAI_MODEL         gpt-5.6-sol
   HESABU_ACCESS_CODE   Your private study code, at least 16 characters
   SESSION_SECRET      A random secret, at least 32 characters
7. Deploy, open the site, and enter your study code when starting live AI.

Generate a private session secret on your computer:
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"

Never upload real keys to GitHub or put them in frontend files.
Redeploy after changing Vercel environment variables.

No database is required. Your study history stays in your browser.
Use Settings to export backups before switching devices or domains.

README.md has the full guide. TEST_REPORT.md states what was tested.
The included sample is labeled and does not use live AI.
Your deployment needs a live API check with your own key and model access.
